สำหรับผู้ทำรอบ OT

  1. เลือกรอบเดือนเช่น รอบเดือนกันยายน คือวันที่ 16 สิงหาคม ถึง 15 กันยายน
  2. เลือกไฟล์เวรให้ครบ 3 หน่วยเลือก LAB, Molec และ Bacteria ของรอบนั้น
  3. ใส่วันที่ 00000328 ถ้ามีใส่เฉพาะวันที่ HR แจ้งช่วงปีใหม่หรือสงกรานต์ ถ้าเดือนไหนไม่มีให้ข้าม
  4. ดึงวันลาตรวจจำนวนวันลาที่ดึงมา และดูว่ามีรายการใดตรงกับเวรหรือไม่
  5. ตรวจสรุป OTเช็กชื่อ ชั่วโมง และรายการเตือนให้เรียบร้อย
  6. บันทึกรอบเมื่อข้อมูลถูกต้องแล้ว กด “ยืนยันและบันทึกรอบนี้”
  7. ติดตามการรับทราบดูหัวข้อ “รับทราบ OT” ว่าใครรับทราบแล้วและใครยังค้างอยู่
  8. ดู Log ล่าสุดของแอพใช้ตรวจการเข้าใช้ การรับทราบ และการทำรายการของผู้ใช้งานในระบบ
  9. ExportExport HR Excel และ Export หลักฐานการรับทราบเมื่อพร้อมส่งงาน

เพิ่มบัญชีเจ้าหน้าที่ครั้งแรก

  1. เปิดเมนู “ผู้ใช้งาน”เลือกชื่อเจ้าหน้าที่ ใส่ Mahidol ID และรหัสผ่านชั่วคราว
  2. กด “สร้างบัญชี”แจ้ง Mahidol ID และรหัสชั่วคราวให้เจ้าหน้าที่คนนั้น
  3. ครั้งแรกที่เข้าใช้ระบบจะให้เจ้าหน้าที่ตั้งรหัสผ่านใหม่ของตนเองก่อนใช้งาน
  4. ลืมรหัสผ่านกด “Reset password” ที่รายชื่อผู้ใช้งาน แล้วตั้งรหัสชั่วคราวใหม่ให้เจ้าหน้าที่

สำหรับเจ้าหน้าที่รับทราบ OT

  1. เข้าสู่ระบบกรอกเฉพาะ Mahidol ID เช่น username.sur และรหัสผ่าน
  2. เปิดรอบ OTดูยอด OT และเปิดรายละเอียดเวรของตนเอง
  3. ตรวจข้อมูลถ้าข้อมูลถูกต้อง ให้ติ๊กข้อความรับทราบ
  4. กด “ยืนยันรับทราบ”เมื่อบันทึกแล้วจะแสดงวันและเวลาที่รับทราบ
  5. ถ้ารายการถูกแก้ภายหลังระบบจะให้รับทราบใหม่เฉพาะรอบที่ข้อมูลของคุณเปลี่ยน

ติดตั้งบนมือถือ

Androidเปิด LAB OT ด้วย Chrome → เลือก “ติดตั้งแอป” หรือ “เพิ่มไปยังหน้าจอหลัก”
iPhone / iPadเปิด LAB OT ด้วย Safari → กด Share → “เพิ่มไปยังหน้าจอโฮม” → เพิ่ม

วิธีใช้

  1. เปิด “OT ของฉัน”เลือกดูรอบ OT และเปิดรายละเอียดเวรของตนเอง
  2. ตรวจเวรจริงเช็กวันที่ หน่วย เวร เวลา และจำนวนชั่วโมงของตนเอง
  3. ตรวจตารางเบิก HRดูวันที่ เวลาเข้า-ออก และวันที่ระบบเว้น รวมถึงวันลาที่ระบบใช้หลบ
  4. กดยืนยันรับทราบเมื่อเวรจริง ตารางเบิก HR และวันที่ระบบเว้นถูกต้องแล้ว จึงติ๊กและกด “ยืนยันรับทราบ”
  5. ถ้าข้อมูลถูกแก้ภายหลังระบบจะให้รับทราบใหม่เฉพาะรอบที่ข้อมูลของคุณเปลี่ยน
  6. เปลี่ยนรหัสผ่านกดปุ่ม “เปลี่ยนรหัสผ่าน” ด้านบนได้ตลอด
